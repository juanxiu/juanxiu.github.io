쿠버네티스 리소스 조회를 로컬 캐시로 개선

2025.07 — 2025.12Go 코드 개선 · Kubernetes 매니페스트 수정

쿠버네티스 배포 관리를 지원하는 Argo CD Agent에서, 애플리케이션 정보를 조회할 때마다 API 서버를 호출하는 비효율을 발견했습니다. 일반 조회에는 기존 로컬 메모리 캐시를 활용하도록 변경해 API 서버의 처리 부담을 줄였습니다.

Application 조회 구조 분석

오픈소스 컨트리뷰션 아카데미에서 GitOps 기반 배포를 지원하는 Argo CD Agent에 기여했습니다. 로컬 클러스터에서 Application 조회 경로를 분석하며, CRD로 정의된 리소스를 조회할 때마다 Kubernetes API 서버를 호출하는 비효율을 확인했습니다.

조회 경로 분리 및 데이터 보호

일반 조회에는 기존 로컬 메모리 캐시를 활용했습니다. 캐시가 실제 리소스 상태보다 늦게 갱신될 수 있어, 최신 정보가 필요한 업데이트용 조회는 Kubernetes API 서버 직접 호출을 유지했습니다.

  • 캐시가 준비되지 않았거나 대상 조회가 실패하면 API 서버로 폴백
  • 업데이트 재시도에서 오래된 정보를 읽지 않도록 조회 경로 분리
  • 호출자가 캐시의 공유 객체를 변경하지 않도록 복사본 반환
  • 수정한 코드의 테스트와 리뷰를 거쳐 공식 프로젝트에 병합

기여 성과

  • 100개 Application 조회 시간: 약 19초에서 0.4밀리초로 단축
  • 같은 실험의 API 호출 횟수: 300회에서 200회로 감소
  • 코드와 매니페스트 개선: 공식 프로젝트에 PR 5개 병합
  • 오픈소스 기여 활동으로 한국IT비즈니스진흥협회장상 수상

공식 프로젝트에 병합한 PR 5개

조회 성능 개선 외에도 API 연동 테스트와 네트워크 정책, 테스트 환경 설정을 보완했습니다. 아래 PR은 모두 공식 저장소에 병합됐습니다.

  • #525Application 조회에 로컬 캐시 적용 ↗

    일반 조회는 로컬 캐시를 사용하고, 최신 정보가 필요한 업데이트용 조회는 API 서버를 직접 호출하도록 분리했습니다.

  • #549Argo CD API 연동 E2E 테스트 추가 ↗

    API로 Application을 생성·조회·삭제하는 시나리오를 추가하고, 인증과 요청 서명을 처리하는 테스트 클라이언트를 보완했습니다.

  • #574Redis 통신을 위한 NetworkPolicy 보완 ↗

    Agent와 Principal이 Redis에 접근할 수 있도록 Helm 템플릿과 Kustomize의 네트워크 정책을 보완했습니다.

  • #603캐시 동기화 대기시간 설정 추가 ↗

    리소스 정보가 캐시에 반영될 때까지 기다리는 시간을 설정하도록 옵션을 추가하고, 기본값과 설정 동작을 단위 테스트로 확인했습니다.

  • #607테스트용 Redis Proxy 비활성화 옵션 추가 ↗

    테스트에서 불필요한 Redis Proxy를 끄고 Principal 서버를 실행할 수 있도록 옵션과 단위 테스트를 추가했습니다.
