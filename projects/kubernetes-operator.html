Kubernetes Operator

배포 상태 점검과 로그 모니터링 구현

스터디 프로젝트Operator 개발 · 배포 상태 모니터링

배포할 때마다 수동으로 확인하던 애플리케이션 상태 점검을 Operator로 구현했습니다. 서비스 준비 상태를 확인해 알리고, Loki로 관련 로그를 조회하도록 연결했습니다.

배포 상태를 직접 확인하던 작업 개선

배포할 때마다 수동으로 조회하던 애플리케이션 상태 점검을 줄이기 위해 Operator를 개발했습니다. Deployment의 배포 진행과 결과를 감지하고, 서비스 준비 여부를 포함한 상태를 운영자에게 전달하도록 구현했습니다.

CRD와 Reconcile을 활용한 리소스 관리

  • CRD로 배포 설정의 구조 정의
  • Reconcile에서 Custom Resource를 읽어 Deployment 구성
  • 실행 상태와 함께 서비스 준비 상태를 확인해 Slack으로 알림
  • 실제 상태 변화와 알림 수신 내역을 대조해 동작 확인

Loki 로그 조회와 테스트 리포트

알림 이후 사람이 관련 애플리케이션의 로그를 찾아보던 반복 작업을 줄이고자, 별도의 로그 조회 기능을 연결했습니다. 관련 로그를 확인하고 테스트 리포트를 작성하도록 구성해 주간 리포트 작성 시간을 150분에서 30분으로 단축했습니다. 작업 지침과 조회 도구는 팀에 공유했습니다.
