매매 기록과 시장 데이터를 연결한 투자 회고

개인 투자자가 매매 이후 판단 근거를 정리하기 어렵다는 문제를 사용자 인터뷰와 대면 UT로 정의하고, 매매 기록과 시장 데이터를 기반으로 개인화된 투자 회고를 생성하는 AI 제품을 기획 및 개발했습니다. 사용자의 의사결정 맥락을 데이터 단위로 재구성하고 관련 근거만 검색해 응답에 반영하는 AI Agent 흐름을 설계했습니다.

Multi-Agent orchestration

Single Agent 호출 구조를 역할 기반 Agent 구조로 전환했습니다. 중앙 에이전트가 사용자 요청에 따라 주식 데이터 에이전트와 사용자 쿼리 에이전트를 호출하도록 설계했습니다.

RAG, tracing, evaluation

Sentence-BERT, ChromaDB, Cross-Encoder reranking으로 회고 맥락에 맞는 근거를 검색하고, Langfuse trace와 LLM-as-a-Judge 평가로 AI 응답 품질을 30%에서 70%로 개선했습니다.

  • 시장 데이터와 매매 시점을 회고 맥락 단위로 재구성하는 RAG 흐름 설계
  • 한국투자증권 API 데이터 수집과 의미 단위 chunking 적용
  • API 호출 제한에 대응하기 위한 exponential backoff 적용

JWT 기반 guardrail

에이전트가 사용자 거래 내역에 직접 접근하지 않도록 JWT에서 검증한 사용자 컨텍스트를 기준으로 데이터 접근 범위를 제한했습니다. 에이전트가 타 사용자의 거래 내역에 접근하지 못하도록 인증 흐름을 설계했습니다.
