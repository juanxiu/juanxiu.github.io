악기 상가의 디지털 전환(DX)을 위한 서비스 구현

팀과 함께 악기 상가를 직접 방문해 점주의 거래 방식과 재고 관리 절차를 파악했습니다. 고객용 예약과 점주용 관리 기능이 하나의 데이터 흐름으로 이어지도록 요구사항을 API 명세와 DB 스키마로 구체화했습니다.

예약 및 재고 동시성 제어

  • 악기 대여 예약과 점주의 재고 관리 기능 개발
  • 예약 저장과 재고 차감을 하나의 트랜잭션으로 묶어 함께 처리
  • 동시 예약에도 재고 수량이 어긋나지 않도록 비관적 락 적용
  • 재고 수량과 거래 상태의 변경 이력 기록

결과동시 예약에 따른 재고 불일치를 방지하고, 변경 이력으로 예약과 재고 상태를 추적할 수 있도록 했습니다.

검색과 서버 오류 모니터링

  • 데이터베이스 인덱스를 적용해 검색 성능 개선
  • QueryDSL로 악기 분류와 대여 가능 여부, 영업시간을 조합한 동적 검색 구현
  • 서버 예외를 Sentry와 연동하고 오류 발생 알림 설정
  • 오류 발생 시점과 내용을 확인할 수 있는 모니터링 환경 구성

현장 협약과 프로젝트 성과

예약과 재고, 영업시간, 검색을 포함한 서버 핵심 기능을 개발했습니다. 악기 상가와 서비스 이용 협약을 맺었습니다. 뮤사이 프로젝트로 세아해암학술장학재단 커리어챌린지에 선정돼, 창업 준비 활동을 위한 장학금 300만 원을 지원받았습니다.
